# Learning Makes Difference — Focus Color Study

## Direction
The product should feel calm, intentional, and study-focused rather than generic SaaS-blue. The color system should support the Core Learning Loop: active recall, repair, scheduling, and focus recovery. Large surfaces stay warm-neutral; color is reserved for actions and factual learning signals.

## Usage rules
1. Use **Deep Pine** for the main action on each page: Start Recall Session, Start Focus, Start Interleaved Session.
2. Replace blue information states with **Factual Teal** or **Sage Focus** so the product feels calmer and less like a generic dashboard.
3. Use **Terracotta** only for weak recall: Forgot, Hard, Needs practice, Practice Repair.
4. Use **Honey Amber** for new or not-yet-recalled material. Amber means “pay attention,” not “failed.”
5. Use **Leaf Success / Deep Pine** for Good, Easy, Recall Today, Due for Recall, and ready states.
6. Avoid mastery percentages, XP-like colors, and progress gradients. The app should show factual learning signals, not gamified confidence.
7. Keep large surfaces warm and quiet. Color should guide the next action, not compete with the content.

## Applied outcome
The seven supplied mockups were recolored to reduce blue usage, strengthen the focus/study identity, and keep status colors aligned with the PRD’s factual learning signals.
